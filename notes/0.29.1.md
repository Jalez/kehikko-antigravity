Kind: feature

- **Edits outside a worktree are refused** while Worktrees is on the kehikko: Antigravity's file writes and replacements in a project's main checkout, or in an installed module's folder, are stopped with how to make a worktree instead. Every command and file edit now goes through one shared guard check, so a new kind of guard a module declares is held here too.

## For agents

- `write_to_file`, `replace_file_content` and `multi_replace_file_content` go through the same guard check as `run_command`. When a module refuses an edit (for example Worktrees, a file in a main checkout), make a worktree as its reason says and edit there.
