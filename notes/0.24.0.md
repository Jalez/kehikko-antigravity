- **Guards hold while Kehikot restarts.** A heavy command a conversation runs while Kehikot is restarting now waits up to 20 seconds for Kehikot to come back and then goes to the queue, instead of running at once without its guards. If Kehikot stays away, the command runs and the conversation is told it ran unguarded and how to queue heavy work itself.
- **Conversations find this module through Kehikot.** A conversation's hooks reach the module through Kehikot's stable address for it first, then wherever the module is registered now, so a module that came back on another port is still found.

## For agents
- If a shell command is let through with a note that Kehikot did not answer, run heavy work (tests, typechecks, builds) through Queue's CLI from the shell in the background (`kehikot-queue run -- <command>`) until Kehikot is back.
