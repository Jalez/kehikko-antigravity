- **Your kehikko's skills reach every session.** The skills you write for a kehikko are given to each Antigravity session started there, as slash commands it can use, and the session is told which they are.
- **Edits arrive while it runs.** A skill you add, change or remove on the kehikko is told to a running session at its next turn, with where to read the new text.

## For agents

- Skills the person wrote for this kehikko load into new sessions and are listed in the notes; one added while you run is read with `kehikko_skills` on the kehikko door.
