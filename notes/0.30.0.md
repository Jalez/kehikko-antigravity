Kind: feature

- **Brings its conversations along when you adopt an item.** When you adopt a merge request or issue that no epic names, Kehikot can list the Antigravity conversations of that project — the ones whose title names it first — so you can file one under the epic, and an undo puts it back. A conversation already filed somewhere else is never moved.
- **Starts a conversation for Kehikot's own tasks.** Kehikot can start a new Antigravity conversation in the project with a brief you approved, filed under its place like any other, and show it on its own while it works.
